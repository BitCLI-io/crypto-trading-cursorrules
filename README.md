## Quick Start (30 Seconds)

1. **Clone this repository:**
   ```bash
   git clone https://github.com/BitCLI-io/crypto-trading-cursorrules.git
   ```
2. **Open in Cursor IDE:**
   Open this folder in Cursor. Cursor will automatically detect the `.cursor/mcp.json` configuration and connect to the BitCLI MCP server.
3. **Ask Cursor Composer (Ctrl/Cmd + I):**
   > *"Scan the market for perpetual futures with high volume spikes and negative funding, calculate position size for $50 risk on the best setup, and arm an alert."*
